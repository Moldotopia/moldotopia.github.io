Stergerea datelor

Data intrarii in vigoare: 13 iunie 2026

Cum sa stergeti datele dumneavoastra

INTIMO functioneaza dupa principiul local-first: cea mai mare parte a continutului dumneavoastra exista doar pe dispozitivul dumneavoastra, iar tot ceea ce impartasiti cu un partener este criptat end-to-end. Prin urmare, stergerea datelor are doua parti.

1. Stergeti datele de pe dispozitiv

In aplicatie, deschideti Setari si apasati Reseteaza toate datele, apoi confirmati. Aceasta sterge definitiv toate datele dumneavoastra locale — activitati, reflectii, dorinte, preferinte, chei de criptare si informatii de imperechere — de pe dispozitiv. Aceasta actiune nu poate fi anulata.

2. Stergeti datele de pe server

INTIMO stocheaza foarte putine date pe serverele sale: inregistrarea dispozitivului si preferintele pentru notificari push. Pentru a le elimina:

  • Gasiti User ID-ul dumneavoastra: in aplicatie, deschideti Setari → Despre Intimo; User ID-ul este afisat acolo.
  • Solicitati stergerea: trimiteti User ID-ul prin email la intisync0@gmail.com cu subiectul „Delete my data”. Procesam solicitarile in termen de 30 de zile.

Ce este sters

  • Pe dispozitivul dumneavoastra (prin Reseteaza toate datele): activitati, reflectii, dorinte, date de planificare, intrari de ciclu, preferinte, chei de criptare si informatii de imperechere.
  • Pe serverele noastre (prin solicitarea dumneavoastra): inregistrarea dispozitivului si preferintele pentru notificari push.

Ce poate fi pastrat

  • Date analitice agregate si anonimizate care nu va pot identifica.
  • Inregistrari minime pe care suntem obligati sa le pastram prin lege.

Important

Stergerea este permanenta si nu poate fi anulata. Continutul pe care l-ati impartasit anterior cu un partener este stocat de asemenea pe dispozitivul partenerului sub propriul cont si este guvernat de alegerile acestuia.
